# Tank Volume Calculator

A tiny, free, open-source calculator for finding the volume and capacity of a cylindrical tank.

Enter the tank diameter and length, choose a measurement unit, and the calculator instantly returns the volume in:

- Liters
- US gallons
- Cubic feet
- Cubic meters

## Features

- Simple cylindrical tank volume calculation
- Metric and imperial input units
- Instant calculations in the browser
- Multiple output units
- No dependencies
- No tracking
- No account required
- Runs entirely client-side

## Formula

The calculator uses the standard cylinder volume formula:

**V = π × r² × L**

where:

- **V** = volume
- **r** = tank radius
- **L** = tank length
